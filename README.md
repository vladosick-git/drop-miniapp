# ДРОП - демо Telegram Mini App магазина уличной одежды

Сверстано 1:1 по трём макетам ChatGPT (`ref/`). Чистый HTML/CSS/JS без сборки, открывается двойным кликом.

| Файл | Что это |
|---|---|
| `index.html` | Mini App: каталог, карточка товара, корзина с оформлением, избранное, профиль, мобильная админка (`#/admin`, `#/admin/orders`, `#/admin/product/runner`) |
| `admin.html` | Веб-админка, дашборд под 1440 px |
| `showcase.html` | Витрина «три телефона рядом», как на макетах (`?set=shop|admin|web`) |

## Что работает по-настоящему
- Корзина: количество, удаление, промокод **DROP14** (-10%, неверный код - «Не найден»), доставка (СДЭК +290 ₽), списание 500 баллов, итог и текст кнопки «Оплатить» пересчитываются.
- Оформление создаёт заказ #1003, и он сразу появляется в мобильной и веб-админке (общий localStorage).
- Админка: фильтры и поиск заказов, «Принять в сборку» → «В доставку» → «Выполнен»; редактирование товара (цена → скидка считается сама, остатки, тумблеры), после сохранения цена меняется в магазине.
- Таймер дропа идёт, избранное, галерея листается.
- Сброс демо: кнопка «Сбросить демо» или `?reset=1`.

Данные моковые, все из макетов (`js/data.js`): 14 открытий, 23 подписчика, заказ #1002 Артёма на 17 032 ₽, тестовый #1001 на 10 ₽. Исправлено расхождение: размер 45 зачёркнут в магазине, поэтому в админке его остаток 0 (в макете было 3). Также исправлены опечатки макета: «Бейдж «Новинка»» и «1 заказ» в подсказке графика.

## Telegram
Подключён `telegram-web-app.js`. Внутри Telegram скрывается нарисованная шапка, кнопки «Добавить в корзину» и «Оплатить» становятся нативной MainButton, работает BackButton, применяются цвета темы (`themeParams`, светлая и тёмная), есть вибрация. Ссылка с `?startapp=admin` открывает админку. Оплата в демо - попап без списания.

## Скриншоты
```
cd tools && npm i   # один раз (puppeteer-core, нужен установленный Chrome)
node tools/shot.js kwork    # screens/*.png, 1920x1280 для Кворка
node tools/shot.js mobile   # screens/mobile/*.png, отдельные экраны 428x971 @3x
node tools/shot.js compare  # tmp/cmp_*.png в размерах макетов
node tools/record.js        # kwork/ДРОП - видео-демо.mp4, 1920x1080 ~63 сек (нужен ffmpeg)
python tools/compare.py shop 1038 100 1468 1000   # макет и рендер рядом
```
Фото сгенерированы GPT по `ТЗ_фото_для_GPT.md`, оригиналы в `incoming_gpt/`. Нарезка под все слоты: `python tools/prepare_photos.py`. Старые вырезки из макетов лежат в `ref/old_crops/` (`tools/extract_assets.py`).

Готовый комплект для портфолио Кворка лежит локально в `kwork/` (в репозиторий не входит) (картинки по порядку, видео, тексты в `Кворк - что вставлять.txt`).
